## Slide 5: Demo Walkthrough
**Headline:** End-to-end flow works from signup to billing management.
- Signup/login into protected app shell.
- Start generation from Create page; track queued to completed states.
- Use credits in-app; hit upgrade prompts when limits are reached.
- Start Stripe checkout and manage subscription in Stripe portal.
- Subscription status persists via webhook sync back into app state.
